# NutRise Mobile

NutRise Mobile is a React Native Expo application developed for nutrition, water intake, workout tracking, and daily health progress monitoring.

The mobile app is integrated with the NutRise Spring Boot backend and uses JWT-based authentication for secure user sessions.

##  Features

- User login and registration
- Secure JWT-based session handling
- Daily calorie tracking
- Meal logging
- Water intake tracking
- Workout logging
- Daily progress dashboard
- Motivation card
- Backend API integration
- Secure token storage

##  Tech Stack

- React Native
- Expo
- TypeScript
- React Navigation
- Axios
- Expo Secure Store
- Spring Boot Backend API
